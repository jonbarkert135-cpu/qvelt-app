# QVELT project skills

The baseline skills are original project instructions added with the owner's authorization.
`ponytail/SKILL.md` is the owner's corrected upload (MIT metadata), designated
primary for coding tasks. Only its YAML description was unfolded onto one line
for the existing validator; its instructions are unchanged. No executable scripts
or external instructions were fetched. The earlier Playwright upload was supplied
by mistake and has not been retained as a project skill.
Read matching `SKILL.md` files before each task; AGENTS.md and ADRs take precedence.

| Skill | Use |
| --- | --- |
| ponytail | Primary coding workflow; minimal complete solutions |
| verify-before-claiming | Every code change and completion report |
| tdd-small-steps | Every code change |
| security-untrusted-input | Auth, tenancy, files, tools, repositories and URLs |
| math-and-numerics-check | Calculations, units, budgets and expiry boundaries |

`qvelt-chat-ui-design` has not been authored yet. UI work must first supply that
skill and read `docs/DESIGN_BRIEF.md`; backend work does not require it.
Do not fetch third-party skills without the vetting in `docs/skills/SKILLS.md`.
